Step: search query refinement. A literature search query returned no hits, too many hits, or was rejected by the
source. You rewrite it once.

The material gives the hypothesis, the source, the query, the problem (with the hit count or the source's
message), and the earlier attempts.

Return one `query` for the same source and purpose, and a one-line `rationale`:
- No hits: broaden (fewer ANDed terms, more synonyms ORed, `TITLE_ABS` / `[tiab]` instead of title only).
- Too many hits: narrow (add a key feature, the population, or a study-type filter).
- Rejected: fix the syntax. Use only the fields of that source's syntax guide; balance quotes and parentheses.
Never repeat an earlier attempt.
